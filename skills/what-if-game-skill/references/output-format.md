# Output Format

Use this format for the default user-facing response.

## 1. 局面标题

One short label for the user's current situation.

Rules:

- 18 Chinese characters or fewer when possible.
- Specific to the situation.
- No mockery.

## 2. 真正的决策点

Reframe the surface question into the real tradeoff.

Example:

```txt
你不是只在选免费还是收费，你是在选：现在优先扩大样本量，还是优先验证付费意愿。
```

## 3. 未来分支

Return three branches.

For each branch:

```txt
### 分支 A：继续免费冲规模

选择动作：
继续降低使用门槛，让更多用户进来。

7 天后：
数据更好看，反馈也更多。

30 天后：
账单开始变成每天都会打开的页面。

90 天后：
如果还没有付费信号，你可能会分不清自己是在验证需求，还是在赞助大家试用。

隐藏代价：
免费会让你更难分辨喜欢、好奇和真正需要。

早期信号：
- 高频用户是否愿意留下联系方式。
- 账单增长是否快过活跃用户增长。
- 用户是否主动问付费版本。

人的状态：
短期更兴奋，长期更容易被增长曲线牵着走。

适合谁：
适合现金流压力不大、还缺样本量的人。
```

## 4. 人的状态变化

Summarize how the branches affect the user's energy, judgment, agency, stability, and relationship pressure.

Do not use numeric scores. Use short reality-facing sentences.

## 5. 预警信号

List 3-5 observable signals.

Good signals:

- "每周是否都在为同一个问题手动救火。"
- "愿意付费的人是否能说清楚自己为什么付。"
- "团队是否开始用会议替代决策。"

Bad signals:

- "注意风险。"
- "关注用户体验。"
- "保持长期主义。"

## 6. 最小现实动作

Give one action that can be done in 24-72 hours.

It must be:

- Small.
- Reversible.
- Low-cost.
- Able to create new information.

## 7. 结果页式总结

Format:

```txt
你现在像是：边跑边修的试飞员
短注释：飞机已经离地了，但仪表盘还有两个灯在闪。
```

## Required Closing Note

End with a short caveat:

```txt
这不是预测，只是一场现实预演。真正有价值的是你接下来观察哪些信号。
```
