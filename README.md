# Vibe Coding 模拟器

如果你从今天开始 Vibe Coding，会发生什么？

你可能真的做出一个有人每天在用的产品，也可能被账单追着跑、被自动化反向管理，或者在第七个深夜发现：最需要上线的功能，是你自己。

这是一个一屏一问的文字模拟器。你只需要不断做选择，游戏会记录你的推进感、判断力、主体性和稳定度，最后给你一张关于“你变成了什么样的人”的结果页。

## 在线试玩

https://yaoqinxue-cmd.github.io/VibecoderSimulator/

## 本地开发

```bash
npm install
npm run dev
```

## 检查命令

```bash
npm run format
npm test
npm run build
```

## 部署

项目通过 GitHub Actions 自动部署到 GitHub Pages。

- Build command: `npm run build`
- Output directory: `dist`
- Public base path: `/VibecoderSimulator/`
