# Vibe Coding Simulator

Vibe Coding Simulator is a browser-based text simulator about what happens after you start vibe coding: the product gets built, users arrive, bills arrive, and eventually the game tells you what kind of person you became.

Play online:

https://yaoqinxue-cmd.github.io/VibecoderSimulator/

## Local Development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run format
npm test
npm run build
```

## Deployment

This project deploys to GitHub Pages through GitHub Actions.

- Build command: `npm run build`
- Output directory: `dist`
- Public base path: `/VibecoderSimulator/`
